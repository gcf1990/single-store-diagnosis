# 本地 Demo 入口

直接访问裸地址会保持真实集成降级：没有上游人员画像时显示角色识别异常。

本地演示全部经销商入口使用显式参数：

```text
http://127.0.0.1:4180/?demo=all-dealers
```

启用条件同时满足才注入样例数据：

- `hostname` 为 `127.0.0.1` 或 `localhost`
- URL 参数 `demo=all-dealers`

该入口会在应用初始化前写入总部人员画像，并注入 3 个大区、9 个小区、26 个经销商的本地样例数据。销售概览和过程分析页均可看到“查看所有经销商”，点击后进入扁平分页视图。非本地主机、无参数或其他参数不会注入 Demo 数据。
