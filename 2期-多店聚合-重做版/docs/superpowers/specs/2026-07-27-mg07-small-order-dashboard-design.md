## 3. 信息架构与精确文案

页面 DOM 顺序必须可断言，按以下顺序出现：

1. 销售总览标题 / 筛选区域。
2. `MG 07小订战报`。
3. `销售指标` 与 `过程指标` 两个并列指标组。
4. `门店销售表现` 或当前权限层级对应的销售表现表。

模块标题固定文案：`MG 07小订战报`

标题右侧必须保留独立状态 Badge，文案只能来自小订状态机：`小订即将开始`、`小订进行中`、`小订已结束`。该 Badge 不复用销售总览、过程分析或打铁状态。

摘要区固定五项经营指标，顺序不可调整：

1. `小订目标`
2. `留存小订`
3. `今日新增`
4. `目标达成`
5. `时间进度`

五项经营指标右侧固定保留第六个动态层级位：

| 当前战报层级 | label | value | 单位 |
|---|---|---|---|
| 总部看大区 | `落后大区` | 当前可见大区中 `gap_to_expected > 0` 的对象数量 | 个 |
| 大区看小区 | `落后小区` | 当前可见小区中 `gap_to_expected > 0` 的对象数量 | 个 |
| 小区看门店 | `落后门店` | 当前可见门店中 `gap_to_expected > 0` 的对象数量 | 个 |
| 单门店 | `自身进度状态` | `领先` / `落后` / `零目标` / `数据暂不可用` | 无 |

状态文案固定三种：`小订即将开始`、`小订进行中`、`小订已结束`。

`层级动态落后对象`仅指上表第六动态位，不替换具体对象名称；对象名称只在展开后的 `小订达成表现` 列表中展示。

六卡视觉与语义合同：

- 六张卡顺序固定为 `小订目标`、`留存小订`、`今日新增`、`目标达成`、`时间进度`、第六动态位，不得换序、合并或移入表格。
- 第一张 `小订目标` 使用蓝色目标语义；第四张 `目标达成`、第六动态位在落后或风险状态下使用红色风险语义。
- 第二张 `留存小订` 主值展示 `retained_small_order`，辅助文本必须展示 `累计 <actual_small_order_all>`；不得把退订数放入该卡辅助文案。
- 第三张 `今日新增` 主值只展示带正号的当天小订数，例如 `+216` 或 `+0`；不得展示“当日小订”等辅助小字。无可用当日实绩时展示 `--`。
- 第六动态位必须同时展示落后对象数和当前层级总对象数，例如 `2 共 7 个大区`；层级变化时 label、单位和总对象文案同步变化。
- 单门店层第六动态位不展示对象数，展示 `领先` / `落后` / `零目标` / `数据暂不可用`。

展开区标题固定文案：`小订达成表现`

展开/收起交互：

- 默认收起，仅展示摘要和展开入口；展开后显示当前层级对象列表，并把入口文案切换为收起状态。

比较条合同：

- 摘要下方必须展示达成/时间进度比较条，左侧文案为 `目标达成 <achievement_rate>%`，并显示 `领先时间进度 <x.xpp>` 或 `落后时间进度 <x.xpp>`。

## 7. 计算公式与异常规则

基础字段：

- `target_total`：目标数据集 RLS 当前可见、且匹配当前顶部范围的目标源行 `MG07小订目标` 求和；范围匹配优先用目标表 `区域 / MAC / 一级经销商`。总部全国全范围必须为 `30001`。
- `actual_small_order_all`：当前权限与当前战报层级范围内，所有 MG 07 一级经销商的 `当日首触小订数` 求和，用于页面 `累计小订`。
- `today_added_small_order`：运行时自然日且固定小订期内的当日 MG 07 小订数，按当前权限与当前战报层级范围汇总；只作展示，不参与达成、缺口、状态、排序或下钻。
- `achievement_actual`：summary 目标达成分子，等于当前权限与当前战报层级范围内所有 MG 07 一级经销商的 `当日首触小订数` 求和，即与 `actual_small_order_all` 同口径；未设目标实际也计入父级达成分子。
- `retained_small_order`：同范围 `当日首触留存小订数` 求和。
- `cancelled_small_order`：同范围 `当日首触小订退订数` 求和。
- `data_updated_at`：本次实际结果中 `调度时间` 的最大值。
- `period_progress`：§4 时间进度，取值 `0` 到 `1`。
- `expected_by_time`：`target_total * period_progress`。
- `gap_to_expected`：summary 使用 `max(0, expected_by_time - actual_small_order_all)`；门店层未设目标实际行不计算应达缺口。
- `achievement_rate`：`actual_small_order_all / target_total`。

展示规则：

- `小订目标`：展示 `target_total`，整数千分位。
- `留存小订`：主值展示 `retained_small_order`，整数千分位；辅助文案展示 `累计 <actual_small_order_all>`。
- `今日新增`：统计日位于固定小订期内且有可用当日实绩时，展示带正号整数，例如 `+216` 或 `+0`；统计日早于开始、晚于结束、当天无数据、实际源不可用或字段不可证时展示 `--`；不得展示辅助小字。
- `目标达成`：当 `target_total > 0` 时展示百分比，保留 1 位小数，不封顶；当 `target_total = 0` 时展示 `--`。
- `时间进度`：展示 `period_progress * 100%`，保留 1 位小数。
- 第六动态位：前三层 value 为当前下一层 `gap_to_expected > 0` 的对象数量，单位统一为 `个`；单门店 value 为 `领先`、`落后`、`零目标` 或 `数据暂不可用`。
- 摘要副标题必须显示 `data_updated_at` 对应的真实数据更新时间；实际未查询或失败时不显示虚假时间。

目标为 0：

- 目标行保留，计入 403 家和零目标门店审计。
- `目标达成`展示 `--`，不做除零。
- `expected_by_time = 0`，`gap_to_expected = 0`。
- 若实际小订大于 0，进入 `zero_target_actual` 审计；该实际计入 `累计小订` 和上级组织 `achievement_actual`，但该零目标门店自身 `目标达成`仍展示 `--`。

目标有实际无：

- 生成目标对象行。
- `actual_small_order_all = 0`、`achievement_actual = 0`，`achievement_rate = 0.0%`。
- 按时间进度计算 `gap_to_expected`，进入达成表现列表。

实际有、目标无：

- 进入 `unconfigured_actual` 审计。
- 实际计入 `累计小订` 和 summary `目标达成`分子，但不并入 `小订目标`分母。
- 门店层目标显示“未设目标”、达成率显示“--”，不判落后、不显示风险；允许作为未设目标实际行出现在小订达成清单。
- QA 审计输出一级经销商代码、实际小订数和来源日期范围，页面不得把该门店渲染成 `0%`、落后或风险。

## 10. 技术模块边界

建议新增独立模块，不把逻辑塞入现有销售目标链路：

| 模块 | 职责 |
|---|---|
| `small-order-config` | 读取固定小订期、目标数据集 `dsId`、实际数据集 `dsId`、字段合同 |
| `small-order-api` | 并行读取目标数据和实际 SQL 聚合，返回来源状态和审计 |
| `small-order-model` | 归一目标、归一实际、权限裁剪、组织聚合、计算达成率和应达缺口 |
| `small-order-view` | 渲染摘要、状态、展开列表和独立下钻 |
| `small-order-validation` | 固定样本、日期边界、权限和响应式测试 |

并行加载：

- 主应用完成用户身份与组织权限解析后，战报目标与实际并行请求。
- 战报请求不得阻塞销售事实、车系枚举、销售概览、过程分析或打铁指标渲染。
- 目标请求和实际请求各自有独立状态；任一失败只降级战报对应区域。

请求身份隔离：

- 战报使用独立请求 token，例如 `smallOrderLoadToken`。
- 缓存 key 至少包含：模块名、用户身份摘要、组织权限范围、战报下钻路径、目标 `dsId`、实际 `dsId`、固定小订期、当前统计截止日。
- 不复用销售概览 `vehicleSeries` cache key，不复用月目标 cache key，不让旧战报响应覆盖新战报状态。

失败降级：

| 失败场景 | 页面行为 | 主应用影响 |
|---|---|---|
| 目标配置缺失或目标源失败 | 摘要显示小订目标暂不可用，达成表现不可展开 | 销售/过程/打铁不受影响 |
| 实际源失败 | 保留目标和时间进度，留存小订、累计辅助与目标达成显示数据暂不可用 | 销售/过程/打铁不受影响 |
| 权限失败 | 战报显示暂无该范围数据权限 | 不扩大范围，不反推无权限 |
| 字段缺失或完整性不可证 | 战报显示数据不完整 | 不用 0 或旧缓存伪装成功 |
| 当前权限下目标和实际均为空 | 显示空态，文案为当前范围暂无 MG 07 小订战报数据 | 不等同无权限 |
