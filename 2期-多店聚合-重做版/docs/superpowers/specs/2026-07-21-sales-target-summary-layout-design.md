# PC 销售指标标题摘要布局设计

**状态：** 已开发，代码审查与独立 QA 通过，测试环境 App `q0844640cf6734877a3193d6` 已发布
**日期：** 2026-07-21

**示意资产：** `.superpowers/brainstorm/49110-1784634166/content/target-summary-final-two-line-deltas.html`

## 1. 结论

PC 顶部销售指标区采用“标题摘要 + 卡内两行环比”的最终方案。月目标和达成率不再放在订单卡第二行，而是迁移到“销售指标”标题行右侧作为次级摘要；顶部全部指标卡只展示指标值、月环比、周环比。

本文件为 PC 最新确认稿。如历史文档仍描述“顶部订单卡第二行展示月目标、目标达成”，以 `Product-Spec.md` REQ-011 v1.64 与本文件为准；该旧规则被本轮替换。

## 2. 布局规则

1. “销售指标”标题本体保持主层级，字号 20px、字重 700。
2. 标题右侧展示目标摘要：`订单目标：22,487　达成率：49.5%`。
3. 标题与摘要之间使用轻分割线；分割线只承担层级分隔，不做强提示。
4. 摘要标签使用 13px、500、灰蓝色。
5. 摘要数值使用 15px、700；订单目标数值使用蓝色，达成率数值使用绿色。
6. 1280px 与 1440px PC 视口下，标题和摘要允许在同一区域内换行；摘要必须弱于标题，不能抢主标题层级。

## 3. 指标卡规则

1. 顶部订单、交付率、零售和四张过程指标卡统一恢复为三段信息：指标值、月环比、周环比。
2. 月环比和周环比必须上下两行展示，禁止同一行横向并排。
3. 环比文本不得因卡片宽度被截断；必要时通过卡内纵向间距和稳定高度消化。
4. 卡片内不得展示月目标、目标达成、订单目标、达成率、目标空槽、目标错误提示或目标加载骨架。
5. 正负趋势颜色沿用现有语义，本轮不改变环比计算口径。

## 4. 状态规则

| 状态 | 标题摘要行为 | 指标卡行为 | 主链路 |
| --- | --- | --- | --- |
| 有有效月目标 | 展示 `订单目标：{月目标}　达成率：{目标达成率}` | 只展示指标值、月环比、周环比 | 正常 |
| 无有效月目标 | 隐藏摘要，不新增提示 | 只展示指标值、月环比、周环比 | 正常 |
| 目标请求失败/无权限/业务码失败 | 在标题摘要位置显示 `月目标数据暂不可用` | 只展示指标值、月环比、周环比 | 正常 |
| 目标加载中 | 在标题摘要位置显示同尺寸加载骨架 | 只展示指标值、月环比、周环比 | 正常 |

## 5. 不变范围

1. 表格订单表现保持“月目标｜目标达成 / 排名｜占比”。
2. 目标数据口径、目标口径实际订单查询、车系筛选、组织筛选、行权限、目标自然键、目标守恒、导出字段均不变。
3. 过程卡数据、过程卡顺序、排名、占比、组织下钻和门店详情跳转均不变。
4. 不新增“覆盖达成”“覆盖不足”“部分车系无目标”“部分门店无目标”等提示、图标或 Tooltip。
5. 不修改移动端；`DEV-PLAN.md` 仅同步本轮 Phase 3F.3 发布事实。代码、测试、构建与测试环境发布均已完成并通过相应验收。
