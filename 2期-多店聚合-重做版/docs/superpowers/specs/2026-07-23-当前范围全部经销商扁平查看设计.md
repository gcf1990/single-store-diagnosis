# 当前范围全部经销商扁平查看设计

> 版本：v1.77
> 日期：2026-07-23
> 范围：PC 表现区“销售概览 / 过程分析 / 打铁指标”共享当前范围全部经销商扁平查看；不改顶部指标、不新增数据集、不改变打铁 11 项公式/目标/SQL-only/车系 fail-closed。
> 状态：v1.73 的销售概览/过程分析范围已独立 Review 与最终 QA 通过，本地实现完成；AC-186～AC-198 全部完成。v1.77 打铁扩展 AC-214～AC-225 最终本地 QA PASS，已发布测试 App；发布后线上 QA 仅有限 PASS，登录态业务 UI 终验未完成。未发布生产、未 commit、未 push。

## 1. 目标

让总部、大区用户在保留分层下钻能力的同时，可以在“销售概览 / 过程分析 / 打铁指标”三张一级 Tab 中一键查看“当前数据范围内全部经销商”。

- 全国范围：展示全国当前可见经销商。
- 大区范围：展示该大区当前可见经销商。
- 当前已下钻路径：总部从大区层手动下钻进入某大区的小区层（真实 `viewLevel=district`、`drillPath` 仅含该大区）时，展示该大区当前可见经销商。真实 `store` 层已经是经销商清单，不再提供入口。

## 2. 入口位置

入口放在表现区 header 工具区、导出按钮左侧。

默认文案：`查看所有经销商`
激活文案：`返回分层查看`

不放入 sticky 操作列表头，原因：

- 操作列宽度只有约 6%-8%，完整文字按钮会挤压表格。
- 操作列表头语义是行级动作列，模式切换是表级动作。
- sticky 列需要稳定宽度，放入模式按钮会增加横向溢出和响应式风险。

## 3. 显隐规则

| 状态 | 入口 |
|---|---|
| 销售概览，真实 `viewLevel != store`，当前有效经销商集合 `> 1`，且无全局加载/空/错误/无权限 | 显示 |
| 过程分析，真实 `viewLevel != store`，当前有效经销商集合 `> 1`，无全局加载/空/错误/无权限，且无过程局部错误 | 显示 |
| 打铁指标，真实 `viewLevel != store`，当前有效经销商集合 `> 1`，无全局加载/空/错误/无权限，且无打铁局部阻断错误 | 显示 |
| 销售概览/过程分析/打铁指标已激活扁平模式 | 显示“返回分层查看” |
| 真实 `viewLevel = store` | 隐藏 |
| 当前有效经销商集合 `<= 1` | 隐藏 |
| 过程分析局部错误态 | 隐藏 |
| 打铁指标局部阻断错误态 | 隐藏 |
| 全局加载、空、错误、无权限 | 隐藏 |

若已处于 `allDealerMode=true`，即使后续真实范围因状态变化收窄到单门店，入口也必须保留“返回分层查看”，保证用户能退出扁平态。

## 4. 状态机

页面展示状态 `allDealerMode` 由销售概览、过程分析和打铁指标共享。

- 默认：`allDealerMode=false`，按 `organization.viewLevel / drillPath` 分层展示。
- 激活：`allDealerMode=true`，保存进入前 `organization.viewLevel / drillPath`、销售页码、过程页码、打铁页码、打铁二级组和 `selectedStoreCode` 快照，不改写真实组织状态，只派生 `effectiveLevel=store`。
- 扁平态三张 Tab：冻结真实组织状态，面包屑返回按钮隐藏，返回事件不生效。
- 关闭：恢复快照中的 `organization.viewLevel / drillPath`、销售页码、过程页码、打铁页码、打铁二级组和 `selectedStoreCode`。
- 上游 Query 变化：清空 `allDealerMode`，回到角色和筛选决定的默认入口。
- 一级 Tab 切换：保留 `allDealerMode`、快照和各 Tab 页码。
- 打铁二级组切换：只改变 `activeMetricGroup`，不得清空 `allDealerMode`、不得恢复分层、不得改变当前扁平范围、打铁页码或入口文案。

## 5. 范围和口径

扁平范围固定为：

`上游 URL 筛选 ∩ 罗盘行权限 ∩ 有效经销商白名单 ∩ 当前 drillPath`

可达路径示例：

- 总部全域，真实 `viewLevel=area`：扁平展示全国当前可见经销商。
- 总部手动下钻到某大区的小区层，真实 `viewLevel=district` 且 `drillPath=[area]`：扁平展示该大区当前可见经销商。
- 大区用户默认小区层，真实 `viewLevel=district`：扁平展示该大区当前可见经销商。
- 真实 `viewLevel=store`：已经是经销商清单，入口隐藏。

数据来源沿用现有已过滤集合：

- 销售概览：`state.data.stores`
- 过程分析：`processBaselineData.stores`
- 打铁指标：既有 `ironStores` / 无车系 `processBaselineData` 组织骨架，以及 Phase 3O 的 SQL-only 指标结果

不新增数据集，不触发新全量查询，不绕过权限。打铁不得使用销售 `汇报车系名称` 过滤后的销售行集补齐行，不得改变来源级 SQL-only、车系字段 fail-closed、DCC 新表或完整性门禁。

## 6. 展示规则

- 销售标题：`全部经销商销售表现`
- 过程标题：`全部经销商过程表现`
- 打铁标题：`全部经销商打铁表现`
- 首列：`经销商名称`
- 操作列：仅 `门店详情`
- 范围文案：保留当前真实组织范围，不追加门店名和角色名。
- 顶部指标：不随扁平清单变化。
- 打铁二级切换：保留 `邀约指标 7 / 试驾指标 4` 现有分段按钮；切组只替换指标列，不改变扁平状态。

## 7. 排名、分页、导出

- 订单/零售排名：在当前扁平经销商集合内统一排名。
- 订单/零售占比：分母为当前扁平经销商集合的订单/零售合计。
- 不按所属小区拆分排名或占比。
- 每页 15 家，经销商总数决定总页数。
- 导出包含当前扁平范围全部经销商，不只导出当前页。
- 打铁导出只包含当前激活二级组在当前扁平范围内的全部经销商行，字段沿用打铁现有当前值、月环比、周环比、来源状态和完整性字段；不新增第二个导出按钮。
